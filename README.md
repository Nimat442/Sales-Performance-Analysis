# Sales-Performance-Analysis

##  Overview

A Power BI portfolio project analyzing sales performance, product trends, and orders and returns to identify key business insights and performance patterns.

##  Objectives

- Analyze sales performance and trends
- Track key business KPIs
- Examine product and regional performance
- Analyze orders and returns
- Present findings through interactive dashboards

##  Tools & Technologies

- Power BI
- DAX
- Power Query
- Microsoft Excel

##  Analysis

The project includes:

- Adidas Sales Analysis
- Orders & Returns Analysis
- Sales performance trends
- Product performance
- Key business KPIs
- Return patterns



##  Skills Demonstrated

Data Analysis • Business Intelligence • Power BI • DAX • Data Visualization • KPI Development • Exploratory Analysis
